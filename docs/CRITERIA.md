# Критерии оценки

Максимум: 100 баллов.

## 1. Работоспособность MVP — до 30 баллов

Наша цель:
- рабочий публично доступный сайт;
- полный пользовательский сценарий от входных данных до результата;
- пользователь может изменить параметры и пересчитать решение;
- проект должен иметь локальный fallback на случай проблем с интернетом.

Для нашего кейса:
- ввод запасов продукции;
- ввод покупателей, спроса и закупочных цен;
- ввод доступных машин;
- расчет оптимального плана поставок;
- отображение выручки, транспортных затрат, прибыли и остатков;
- пересчет после поломки машины или изменения цены.

## 2. Корректность решения — до 25 баллов

Критически важно:
- нельзя отгрузить больше продукции, чем есть на складе;
- нельзя превысить спрос покупателя;
- нельзя превысить доступную вместимость транспорта;
- все финансовые показатели должны считаться корректно;
- после изменения исходных условий план должен реально пересчитываться;
- алгоритм должен решать задачу оптимизации, а не возвращать заранее заданные значения.

Целевая функция:
максимизация прибыли = выручка - транспортные затраты.

## 3. Удобство использования — до 20 баллов

Интерфейс должен быть:
- простым;
- понятным без дополнительного объяснения;
- логичным для пользователя;
- без лишних экранов и сложных настроек.

Желательно:
- один основной dashboard;
- понятные карточки продукции, покупателей и транспорта;
- большая кнопка расчета;
- наглядный результат;
- сравнение результата до и после изменения условий.

## 4. Техническая реализация — до 15 баллов

Предполагаемый стек:
- React для frontend;
- FastAPI для backend;
- Python;
- PuLP или OR-Tools для математической оптимизации.

Главный принцип:
не усложнять архитектуру без необходимости.

Не нужны ради баллов:
- микросервисы;
- Kubernetes;
- сложная инфраструктура;
- лишняя база данных;
- технологии, которые не влияют на работу MVP.

## 5. Защита и перспективы — до 10 баллов

На защите нужно показать:
1. исходные данные;
2. расчет оптимального плана;
3. прибыль и ограничения;
4. поломку одной машины;
5. изменение цены;
6. повторный расчет;
7. сравнение результата до и после.

Позиционирование проекта:

Система помогает фермерским хозяйствам, агрокооперативам и региональным поставщикам эффективнее распределять скоропортящуюся продукцию между покупателями.

Потенциальная ценность для Обнинска и региона:
- снижение потерь скоропортящейся продукции;
- повышение прибыли производителей;
- более эффективное использование транспорта;
- быстрое принятие решений при изменении спроса, цен или доступности машин;
- возможность дальнейшей интеграции с реальными ERP/WMS/TMS системами.

## Наш приоритет

1. Корректный математический оптимизатор.
2. Полностью рабочий пользовательский сценарий.
3. Простой интерфейс.
4. Надежный публичный деплой.
5. Сильная демонстрация.
6. Дополнительные функции только после закрытия обязательного MVP.
